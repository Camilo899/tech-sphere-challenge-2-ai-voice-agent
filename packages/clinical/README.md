# Clinical Core

## Purpose

The Clinical Core contains the business rules of the postoperative follow-up system.

This module is independent from:

- LLM providers
- Voice providers
- Databases
- Frameworks

The objective is to keep the clinical domain isolated from external technologies.

## Responsibilities

- Manage the follow-up lifecycle
- Represent the clinical domain
- Evaluate patient observations
- Generate clinical decisions
- Produce clinical summaries

## Principles

- Domain First
- Framework Agnostic
- Testable
- Traceable
- Auditable
